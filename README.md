# 墨阅 Moread

一个本地优先的私人阅读空间。手机和电脑都能用，支持 EPUB / TXT / HTML / Markdown，自动识别章节、记住阅读位置，并可选地把进度与排版同步到自建云端。

界面采用暖纸、墨绿与琥珀色的编辑式视觉；阅读区与书架主题彼此独立，白天夜里都能安静地读下去。

## 功能

- **书架管理**：导入、搜索、按在读 / 未读 / 读完筛选，按最近阅读、加入时间或书名排序。
- **自动章节**：从 TXT 的中文章节标题、Markdown 标题和 EPUB 目录中识别章节；没有标题的长文会自动分段。
- **排版控制**：7 套主题 + 自定义背景/文字色，5 种字体，字号、行距、字距、段距、页边距、阅读宽度均可调，支持两端对齐与首行缩进。
- **两种阅读模式**：左右翻页或上下滚动；翻页有轻量动画，可随时切换。
- **进度与书签**：自动保存章节、页码、百分比、阅读时长；关闭页面或切到后台也会落盘。书签可添加、跳转、删除。
- **全书搜索**：跨章节搜索，结果显示前后文；点击结果直接跳到对应位置并高亮。
- **听书**：系统语音 / GPT-SoVITS 双引擎。系统语音直接调用设备引擎，可手动选择音色、离线使用；GPT-SoVITS 连接自建服务，用参考音频复刻音色。两种模式都逐句朗读、自动跟随翻页并跨章节继续，语速支持 0.5×–2×。PWA 的系统语音使用浏览器 Web Speech，Android APK 使用系统 TextToSpeech。
- **键盘与触屏**：方向键 / 空格翻页，`←` `→` 翻页，`T` 目录，`D` 显示设置，`L` 听书，`B` 书签，`/` 搜索，`F` 全屏；手机支持左右滑动、左右边缘点击、中央轻点隐藏工具栏。阅读中按安卓返回手势会先关闭目录或搜索，未打开面板时返回书架，不会直接退出应用。
- **云同步（可选）**：只同步阅读进度与阅读设置，按书籍内容指纹匹配；同一本书在另一台设备导入后，进度会自动接上。书籍文件永远留在本机。
- **PWA / 离线**：安装到桌面或主屏，首次加载后离线仍可打开书架和已导入的书。
- **无前端依赖**：原生 ES Modules、IndexedDB、Service Worker；同步服务也只用 Node 标准库。

## 支持格式

| 格式 | 说明 |
| --- | --- |
| `.epub` | EPUB 2 / 3，解析目录、封面与内嵌图片 |
| `.txt` / `.text` | UTF-8 / UTF-16 / GB18030 等常见编码自动探测 |
| `.md` / `.markdown` | 标题作为章节，支持常用 Markdown 语法 |
| `.html` / `.htm` / `.xhtml` | 提取正文，清理脚本与危险标签 |

暂不支持 PDF、MOBI、AZW3 和带 DRM 的电子书；导入时会给出明确提示。

## 快速开始

需要 Node.js 20 或更高版本。

```bash
npm start
```

打开 <http://localhost:4173>。服务同时提供静态页面和同步 API，零第三方依赖。

首次进入可以导入自己的书，或点击「读一读示例书」体验完整阅读器。

### Android APK

GitHub Actions 的「Build Android APK」工作流会在推送 `v*` 标签或手动触发时构建调试 APK，产物名为 `moread-apk-<run>`。APK 通过 Capacitor 打包前端，并使用 `@capacitor-community/text-to-speech` 调用 Android 系统语音引擎。

听书默认使用手机自带的文字转语音引擎。如果听书面板提示未检测到引擎，请进入「设置 → 辅助功能 → 无障碍 → 文本转语音」启用或安装语音引擎后再试；PWA 需要浏览器支持 Web Speech，Android 手机建议直接安装 APK。

### 可选：GPT-SoVITS 听书

听书面板提供「系统语音」和「GPT-SoVITS」两个引擎。选择 GPT-SoVITS 后，墨阅会把当前句子逐句发给你的 GPT-SoVITS 服务合成，再用 Web Audio 播放；系统语音引擎和原有音色、语速设置不会受到影响。

在听书面板中填写：

| 配置 | 说明 |
| --- | --- |
| API 地址 | GPT-SoVITS 服务根地址，例如 `http://100.68.97.6:9881`。可以省略 `http://`。 |
| 接口格式 | 默认「自动识别」。标准 GPT-SoVITS v2 使用 `/tts`；`api_neko` / N.E.K.O-GsvBridge 使用 `/api/v2/tts`。自动模式会优先尝试端口 `9881` 的 `/api/v2/tts`，失败时自动切换。 |
| 参考音频路径 | 服务器文件系统上的音频路径，例如 `/workspace/default_audio/voice.wav`。不是本机文件选择框；GPT-SoVITS 通常要求音频为 3–10 秒。 |
| 参考音频文本 | 参考音频里说的原话，必须尽量一致；这是音色克隆的提示文本。 |
| 参考语言 / 朗读语言 | 通常保持「自动」即可。参考语言需要和参考音频匹配；朗读语言选择「自动识别」时会按正文判断中、日、英、韩。 |
| 超时 | 默认 60 秒，可调 5–180 秒。首次请求包含模型加载，CPU 部署可能需要更久。 |
| 模型路径（可选） | 填写后，墨阅会在合成前调用服务器的 `set_gpt_weights` / `set_sovits_weights` 切换到指定模型；留空则使用服务端当前已加载的模型。 |

填写后先点「测试连接」，成功会朗读一段示例语音。播放时墨阅会预取下一句，并缓存最近几句已解码的音频；暂停后继续会从当前句重新播放。

GPT-SoVITS 是外部服务，使用时需要注意：

- **跨域（CORS）**：服务端必须允许网页跨域请求。`api_neko` 默认允许 `*`；标准 GPT-SoVITS 如果未开放 CORS，需要在服务端或反向代理返回 `Access-Control-Allow-Origin`。APK 能解决 HTTPS 混合内容，但仍受 WebView 的 CORS 限制。
- **HTTPS 混合内容**：如果墨阅运行在 HTTPS 页面（例如部署后的 PWA），浏览器会拦截 `http://` 的 GPT-SoVITS 请求。此时请使用 Android APK，或给 GPT-SoVITS 配置 HTTPS 反向代理；APK 已允许明文 HTTP 和混合内容。
- **网络与模型**：朗读期间需要保持和服务器的连接。参考音频与模型路径都必须是服务端可访问的路径；服务端未加载模型或显存不足时，错误会显示在听书面板中。
- **网络延迟**：逐句合成意味着每句开始前可能等待一次请求。预取会缓解句间停顿，但首句和切换模型后的第一句仍可能较慢。

### 可选：Docker

```bash
docker build -t moread .
docker run -d --name moread -p 4173:4173 -v moread-data:/data moread
```

数据卷 `/data` 中保存账号、令牌和同步数据。也可以直接部署 `server/server.js`，用 Nginx / Caddy 反向代理并启用 HTTPS。

### 环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `4173` | 监听端口 |
| `HOST` | `0.0.0.0` | 监听地址 |
| `DATA_DIR` | `server/data` | 同步数据库目录 |
| `LOG_REQUESTS` | 未启用 | 设为 `1` 打印请求日志 |

## 云同步与隐私

- 书籍正文、封面和文件不会上传。浏览器使用 IndexedDB 保存书籍与章节。
- 云同步只包含：书名 / 作者、章节位置、页码比例、百分比、阅读时长和阅读设置。
- 服务端用 `scrypt` 加盐保存密码哈希，令牌默认 30 天有效；数据库是单个 JSON 文件，写入时原子替换。
- 同步服务默认只允许同源页面和本机静态资源，设置了 CSP、`nosniff`、`frame-ancestors 'none'` 等响应头。
- 不接入任何第三方统计、字体或 CDN。部署到公网时请使用 HTTPS，并自行做好数据卷备份。

在书架右上角点击「登录同步」即可注册账号或登录；登录后可手动「立即同步」，也可以保持自动同步开启。

## 开发与测试

```bash
npm run check   # 对浏览器端、服务端和 Service Worker 做语法检查
npm test        # 章节解析、听书分句 / GPT-SoVITS、工具函数与同步 API 集成测试
```

测试使用 Node 内置的 `node:test`，不会写入真实同步数据；服务端测试会启动临时端口和临时数据目录。

## 已知边界

- PDF / MOBI / AZW3 不在支持范围内。
- 超大型 EPUB 的图片会内联进章节 HTML 以支持离线；特别大的漫画式 EPUB 可能占用较多内存。
- 云同步只匹配已经导入本机的书；换设备后需先导入同一文件，进度才会接上。
- 系统语音的音色、中文发音和离线效果取决于设备已安装的语音引擎；不同浏览器与 Android 设备可选的音色会不同。
- GPT-SoVITS 听书依赖外部服务、网络和服务器上已准备好的参考音频 / 模型；HTTPS 页面访问 HTTP 服务会被浏览器拦截。
- 密码找回需要自行管理数据卷；当前版本没有邮件服务。
